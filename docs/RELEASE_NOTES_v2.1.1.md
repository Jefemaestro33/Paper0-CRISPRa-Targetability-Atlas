# Release v2.1.1 notes

This release supports the BMC Genomics major-revision resubmission. Version
2.1.1 is a public-tree hygiene update to the archived 2.1.0 package: the
scientific tables, figures, workflow, and validation outputs are unchanged,
while internal revision-planning documents were removed from the public source
tree and Zenodo creator metadata was corrected. The current main branch also
records the final GitHub and Zenodo archival links after publication.

Archived release:

- GitHub: https://github.com/Jefemaestro33/Paper0-CRISPRa-Targetability-Atlas/releases/tag/v2.1.1
- Zenodo DOI: https://doi.org/10.5281/zenodo.21970941

## Contents

- revised manuscript source/PDF and figure set;
- tracked source code, Snakemake workflow, environment locks, tests, docs,
  supplementary tables, and analysis statistics;
- selected ignored workflow artifacts in the core archive when present locally:
  BigWig signal tracks, primary/replicate/pooled/matched-depth peak files,
  sensitivity outputs, VM logs, and PNG figure renderings;
- companion reference-input archive containing compressed public `mm39.fa.gz`
  and `gencode.vM33.annotation.gtf.gz` files;
- SHA-256 checksums for the release archives and for archived source inputs.

## Validation

- full configured Snakemake workflow completed on the 2026-08-13 Google Cloud
  VM rebuild;
- final Snakemake dry-run reported no remaining work;
- `analysis_stats/release_validation.txt` reports `PASS`;
- manuscript compiles with `latexmk`;
- release manifest includes tracked files plus selected ignored archival
  artifacts present locally.

## Scope

The resource is a murine microglial CRISPRa guide-site targetability dataset and
prioritization framework. It is not functional CRISPRa validation and does not
claim causal biological-state effects across public datasets generated by
different laboratories.
