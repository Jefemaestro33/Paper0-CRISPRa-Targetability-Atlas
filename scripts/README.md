# Analysis entry points

- `rebuild_atlas_strict_iupac.py`: rebuilds the atlas matrix and sgRNA table
  from local FASTA/promoter/peak inputs using strict IUPAC-aware PAM scanning.
- `analysis_statistics.py`: regenerates statistical summary tables from the
  canonical Table S2 matrix.
- `sync_analysis_outputs.py`: syncs smaller supplementary tables from the
  canonical matrix and statistical outputs.
